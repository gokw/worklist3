# worklist3

Excel(VBAマクロ)で運用していたタスク管理表「worklist」を、ブラウザアプリとして作り直したものです。
GTD(Getting Things Done)の考え方をベースに、頭の中の「やること」を全て書き出して管理します。

## 起動手順

事前に [Node.js](https://nodejs.org/ja)(v20以上)がインストールされている必要があります。

```bash
# 1. 依存ライブラリのインストール(初回のみ)
npm install

# 2. 開発サーバーの起動
npm run dev
```

起動後、表示されたURL(通常 http://localhost:5173)をブラウザで開いてください。

データはブラウザ内(localStorage)に保存されるため、オフラインでも動作し、
ページをリロードしても消えません。ツールバーの 💾 メニューから**エクスポート(JSON保存)/インポート(JSON読込)**ができます。
インポートは同じIDのタスクを重複として登録せず、読込/登録/スキップの件数とスキップ内容を結果ダイアログで確認できます。

## 主な機能

- **タスクの書き出し**: `N` キーで即座に追加フォームが開きます(GTDインボックス)
- **日時と期限の分離**: 「いつやるか(日付+開始予定時刻)」と「いつまでに(期限)」を別々に管理
  - 期限切れは **赤**、期限当日は **黄** で警告表示
- **表示ビュー**: よく使う組み合わせをプリセット化。単独ボタン「今日以降」「予定」＋ドロップダウン「今日/完了/全期間」
  - **今日以降**(既定): 今日以降のタスク＋繰越(普段使い)
  - **予定**: 今日以降で開始予定時刻ありのみ＋繰越(打合せなど時間が決まった予定の確認)
  - **今日**: 選択日のタスク全て＋繰越(集中したいとき。◀▶で特定の日も見られる)
  - **完了**: 完了したものだけ(結果を分析するとき)
  - **全期間**: すべて(棚卸し)
  - 「今日/今日以降/予定」には前日以前の未完了(**繰越**)も表示して忘れ防止(期限切れ色で上部に出る)
  - 表示形式は3種: **表形式** / **表ライト**(Excel並みの高密度。行高約2/3・圧縮見出し・1文字ステータス・等幅数字で桁揃え・アイコン操作) / **カード形式**
  - 表は**列幅を最適化**(日付・繰返は圧縮、タスク名を最大化)。タスク名は**必ず1行**で溢れはホバーで全文表示。**ヘッダーは固定**(スクロールしても残る)
  - **日付が変わる行の下に濃いグレーの実線**を表示。背景色は使わず、状態色(赤黄緑紫グレー)と競合しない。「今日以降」ビューは常に今日から始まるため、上から見て最初の実線がそのまま「今日はここまで」の目安になる
  - **タスク名列はウィンドウ幅に自動フィット**(広げるほどタスク名が伸びる)。最低幅を下回るときだけ表領域内で横スクロール(ページ自体は横スクロールしない)
  - 列の並びは 日付/区分/状態/重要度/繰返/タスク名/見積/開始予定/終了予定/開始/終了/実績/期限/分類(「残り」は非表示)
  - 並び替えは **開始時刻(実績→予定)→終了時刻→重要度→分類名→タスク名** の優先順(日付ごとにまとまる)
- **仕事/個人モード**: 「💼仕事/🏠個人/すべて」をワンクリック(`M`キー)で切替。
  仕事中は仕事のタスクだけ、休日は個人のタスクだけを表示できる
  - 仕事/個人は各タスクが持つ属性(ビュー切替のための軸)。**カテゴリとは独立**
  - 新規タスクは今のビューに合わせて自動設定(仕事ビュー→仕事、個人ビュー→個人。すべてビューでは仕事)。フォームでいつでも変更可
  - 前回のモードを記憶して起動
- **カテゴリ**: タスクの分類・集計のためのラベル(例: ビジネスの中の「運用業務」「稟議チェック」など)。
  仕事/個人とは別軸なので、「運用業務(カテゴリ)の仕事タスク」のように掛け合わせられる
  - 入力は**前方一致インクリメンタルサーチ**のコンボボックス(↑↓/Enter/Escで操作。無ければ新規入力可)
  - 新規タスクは、**タイトルが似た既存タスクのカテゴリを自動で初期表示**(部分一致・直近使用分。自分で触ると自動推測は止まる)
  - 候補は文字順に自動整列
- **タスクの開始/終了**: `S`/`E`キー(または開始/終了ボタン)で時刻入力ミニウィンドウが開く
  - 数字4桁(例 `0930`)またはH:MMで手入力でき、「現在時刻」ボタンも常設
  - **開始**: 開始予定ありならその時刻、なければ現在時刻を初期値に。「続き時間(その日の最終終了時刻)」ボタン付き
  - **終了**: 現在時刻を初期値に。「終了予定(開始予定+見積)」ボタン付き
  - 後からまとめて記録するときに、ボタンで素早く時刻を入れられる
  - この時刻入力ウィンドウは共有部品(`TimeInputDialog`)で、候補ボタンを差し替えて使い回せる
- **ステータス**: Excel版と同じく実績から自動判定(完了=終了実績あり/進行中=開始実績のみ/未着手)。
  自分で設定するのは「待ち」フラグのみ(`W`キーまたはステータスバッジのクリックでON/OFF)
  - 待ちは終了時に自動解除
  - 完了タスクで`W`を押すと「待ちタスク」として複製(見積0・実績クリア。Excel版WaitTask踏襲)
- **重要度**: S(最高)〜E の6段階
- **繰り返しタスク**: 毎日/毎週(曜日指定可)/毎月/毎年、完了からX日後に生成する完了トリガー型
  - 日単位は**0日ごと**も指定可能。完了すると同じ日にすぐ次のタスクが作られる(メール確認など1日に何度も行うものに)
- **中断(割り込み)**: 実行中タスクを「消化分」と「残り」に分割し、割込みタスクを即開始(Excel版ロジック踏襲)
- **コピー**: タスクを複製(`C`キー / コピーボタン)。実行状態(開始・終了実績)はリセットした新規タスクとして作成
  (※以前の「準備」「分割」機能は廃止。Git履歴から復活可能)
- **インライン編集**(表): セルをクリックしてその場で編集(タスク名/見積/日付/開始予定/開始実績/終了実績/重要度/期限/カテゴリ)。
  `Enter`=確定、`Esc`=取消、`Tab`=確定して隣へ。メモ・リンク・繰り返しは詳細ダイアログ(`Enter`/✎)で編集
- **一括編集**: 複数選択(チェック/`Space`)して「✏️ 一括編集」で、日付/期限/カテゴリ/重要度/区分をまとめて変更。
  項目ごとに「変更する」を選ぶので「日付だけ更新」もOK。日付は指定セットと「前日/翌日/今日にずらす」の両方に対応。
  「全選択/選択解除」も用意
- **クリップボード取込**: `V` キーで、Teamsリンク/Outlook予定/通常テキストを自動判別してタスク化
- **複数タスク一括登録**: 「📥 一括登録」でテキストを貼り付け→プレビュー確認→まとめて追加。
  タブ区切りなら「日付→タイトル→カテゴリ→見積」(Excelからの貼り付け向き)、タブ無しなら「日付 タイトル」やタイトルだけでもOK
- **範囲選択**: `Shift`+クリック(基準行〜クリック行)、`Shift`+`↑↓`(キーボードで範囲拡張)。連続時刻・一括編集の対象選びに
- **連続開始時刻**: 選択したタスクに見積時間を積み上げて開始予定を自動設定。
  **選択した順**に割り当てられ(チェックした順に番号が付く)、最初の時刻だけ入力すればOK
- **時刻入力はすべて数字4桁**(例 `0930`。コロン不要)。`0000〜2359` 以外はエラーで弾く
- **定期予定の延期**: 繰り返しタスクを完了にせず「⏭ 次へ」(`P`キー)で次の日程へ移動。「今週はやめた」を1操作で
- **ランダム開始**: 🎲 ボタンで今日のタスクから1件をランダムに開始
- **URLで開き方を指定**: `?mode=&view=&layout=&done=&category=` で開ける(現在の表示状態はURLに自動反映されるのでブックマーク・共有可能)。
  標準は「表形式・今日以降・完了も表示」

## ショートカットキー

### タスクへの操作(↑↓でカーソルを合わせてから)

| キー | 動作 |
|---|---|
| `↑` / `↓` | 行(タスク)を移動(青枠で表示。行クリックでも移動) |
| `←` / `→` | 表内で列(項目)を移動(Excelのセル操作の感覚) |
| `Enter` | カーソルのセルをその場で編集。列未選択なら詳細編集を開く(✎ボタン・編集不可セルのダブルクリックでも開く) |
| `S` | カーソル位置のタスクを開始/再開 |
| `E` | カーソル位置のタスクを終了(繰り返し設定があれば次回分を自動生成) |
| `I` | カーソル位置のタスクを中断(割り込みダイアログ) |
| `W` | 待ちON/OFF。完了タスクの場合は「待ちタスク」として複製 |
| `C` | カーソル位置のタスクを複製(コピー) |
| `P` | 定期タスクを完了にせず次の日程へ延期 |
| `H` / `L` | カーソル位置のタスクの日付を1日戻す/進める(前日/翌日) |
| `Space` | カーソル位置のタスクを選択(連続開始時刻・一括編集の対象) |
| `Delete` | カーソル位置のタスクを削除(確認あり) |

### 全体の操作

| キー | 動作 |
|---|---|
| `N` / `Ctrl+K` | タスク追加フォームを開く |
| `V` | クリップボードから取込(自動判別) |
| `M` | 仕事→個人→すべて のモード巡回 |
| `T` | 表示形式の巡回(表形式→表ライト→カード形式) |
| `Esc` | ダイアログ・セル編集を閉じる |
| `Ctrl+Enter` | フォームの保存(どの入力欄からでも一発保存) |

> 日付の前日/翌日移動は「今日」ビューの ◀▶ ボタン(または日付ピッカー)から行います。

## 技術構成

- React 19 + TypeScript
- Tailwind CSS 4
- Vite 7
- データ保存: localStorage(将来のサーバー同期を見据え、`src/lib/storage.ts` の
  `TaskRepository` インターフェースを差し替えるだけで移行できる構造)

## ディレクトリ構成

```
src/
├── main.tsx            … Reactの起動処理
├── App.tsx             … 画面全体の組み立て・ショートカットキー
├── types.ts            … タスクのデータ構造の定義
├── lib/
│   ├── date.ts         … 日付・時刻の計算
│   ├── storage.ts      … データ保存層(localStorage)
│   ├── logic.ts        … 開始/終了/中断(割込)/繰り返し生成(VBAロジック踏襲)
│   ├── clipboard.ts    … クリップボード自動判別
│   └── sort.ts         … 並び替え(Excel版の優先順位を踏襲)
└── components/         … 画面部品(表・カード・フォーム・ダイアログ類)
VBA/                    … 参考にした元のExcelマクロ
要件.md                 … 要件定義書
```
