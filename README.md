# worklist3

Excel(VBAマクロ)で運用していたタスク管理表「worklist」を、ブラウザアプリとして作り直したものです。
GTD(Getting Things Done)の考え方をベースに、頭の中の「やること」を全て書き出して管理します。

## 起動手順

事前に [Node.js](https://nodejs.org/ja)(v20以上)がインストールされている必要があります。

```bash
# 1. 依存ライブラリのインストール(初回のみ)
npm install

# 2. 開発サーバーの起動
npm run dev
```

起動後、表示されたURL(通常 http://localhost:5173)をブラウザで開いてください。

データはブラウザ内(localStorage)に保存されるため、オフラインでも動作し、
ページをリロードしても消えません。ツールバーの 💾 メニューから**エクスポート(JSON保存)/インポート(JSON読込)**ができます。
エクスポートは **gzip 圧縮(.gz)** を選べます(実測で約20分の1)。インポートは `.json` と `.gz` のどちらもそのまま読めます
(判別は拡張子ではなくファイルの中身で行うので、拡張子が変わっていても読めます)。
💾 メニューの「📋 **表示中をCSVでコピー**」は、**今の絞り込みで表示しているタスク**を
CSV(1行目が見出し `日付,開始,終了,実績分,タスク名,カテゴリ`)にしてクリップボードへ入れます。
生成AIに貼って日記にする、といった用途向け。専用のフィルタは持たず既存の絞り込みをそのまま使うので、
**完了:「完了のみ」＋期間:「カスタム」**で「先週やったこと」を出せます。
`?view=custom&from=2026-07-06&to=2026-07-12&done=onlyDone` をブックマークしておくと一発です。

エクスポートは、**そのとき持っている全タスク**を出力します(ビューの絞り込みは無関係)。
インポートは**差分だけを取り込みます**。無いタスクは追加、**中身が違うタスクはファイルの内容で上書き**、
完全に同じものは何もしません。読込/追加/上書き/変更なしの件数と、上書きした内容を結果ダイアログで確認できます。
上書きするので、**消えた・壊れたデータの復元にそのまま使えます**。

## 自動バックアップ

localStorage だけだと、ブラウザの「サイトデータ削除」やプロファイル破損で**全データが一撃で消えます**。
これを防ぐため、💾 メニューから**バックアップ先フォルダ**(OneDrive等の同期フォルダを想定)を一度選んでおくと、
タスクを変更するたびに自動で控えを書き出します。フォルダを選ばなくてもアプリは従来どおり動きます(付加機能)。

**バックアップ先は「ローカルフォルダ」と「Google ドライブ」から選べます**(排他。同時に両方へは書きません)。
スマートフォンなど File System Access API が使えない環境では、Google ドライブを選べば自動バックアップが働きます。

- **ミラー**: 最新の全タスクを1ファイルへ上書き
  - ローカル: `<フォルダ>/worklist3.json`(変更の約1.5秒後にまとめて1回)
  - Drive: `worklist3/worklist3-<端末名>.json`(変更の約30秒後、および画面を離れたとき)
- **日次コピー**: `backups/` に**14日分**保持し、古いものは自動削除
  (ローカルは `worklist3-日付.json`、Drive は `worklist3-<端末名>-日付.json`。
  **この規約に合う名前のファイル以外には触りません**。圧縮しているときは `.json.gz` も対象)
  - Drive の日次コピーはサーバー側の複製で作るため、通信量は増えません。削除はゴミ箱へ入れます
- **保管形式**: 💾 メニューで **gzip 圧縮**を選べます(既定はローカル=非圧縮 / Drive=圧縮)。
  圧縮したものは書き込む前に展開して読み戻せることを確かめます。
  切り替えると旧形式のミラーは片付けられ、ミラーは常に1つだけ残ります
- **端末名**(Drive のみ): ファイル名に入ります。**端末ごとに違う名前を付けてください**。
  同じ名前だと2台が同じファイルを上書きし合います
- **サニティガード**: 「破損 → 空データを控えに焼き付け → 全消失」を防ぐため、**0件になったとき**と
  **前回比50%以上かつ5件以上減ったとき**は自動上書きを保留し、トーストで知らせます。
  意図した削除だったときは 💾 メニューの「⤓ 今すぐバックアップ」で控えを最新にできます
- **復元**: 消えてしまったら `worklist3.json`(または `backups/` の任意の日付)を 💾 メニューの**インポート**で読み込むだけ。
  インポートは既存タスクも上書きするので、**一部だけ残っている・壊れている状態からでも、その日の状態に戻せます**
- 状態(接続先フォルダ・最終バックアップ時刻・保留やエラー)は 💾 メニュー内に表示されます
- **異常のときはツールバーに「⚠ バックアップ未実行」を常時表示**(Issue #20)。押すと💾メニューへ。
  一時的に承知しているときは「しばらく黙らせる(15/30/60分)」でスヌーズでき、その間は 💤 表示で警告トーストも止まる
  (リロードで解除)。正常に戻れば警告は自動で消える
- 権限はブラウザが管理し、切れたときは「🔄 再接続」を促します
- **ローカルフォルダ**は File System Access API を使うため **Chrome / Edge 専用**。
  **Google ドライブ**は fetch だけで動くのでブラウザを選びません(Client ID の設定が必要。💾 メニュー)
- **Drive の控えからの復元**: 💾 メニューの「♻ Drive の控えから復元」で、ミラーと日次14世代を一覧して選べます。
  選んだ後はいつものインポート(追加読込 / 全リセット読込)に進みます
- **オフライン**(Drive のみ): 圏外では警告を出さず「未送信」と表示し、回線が戻ったら自動で書き込みます

## 主な機能

- **タスクの書き出し**: `N` キーで即座に追加フォームが開きます(GTDインボックス)
- **日時と期限の分離**: 「いつやるか(日付+開始予定時刻)」と「いつまでに(期限)」を別々に管理
  - 期限切れは **赤**、期限当日は **黄** で警告表示
- **絞り込みは3つの独立した軸**の組み合わせ(ツールバー2段目)
  - **期間**: 単独ボタン「今日以降」＋ドロップダウン「今日/全期間/カスタム」
    - **今日以降**(既定): 今日以降のタスク＋繰越(普段使い)
    - **今日**: 選択日のタスク全て＋繰越(集中したいとき。◀▶で特定の日も見られる)
    - **全期間**: すべて(棚卸し)
    - **カスタム**: 開始日〜終了日を指定。**片側を空にすると「この日以降」「この日まで」**になる
      (指定範囲の日付のタスクだけを素直に出す。繰越は混ぜない)
    - 「今日以降/今日」には前日以前の未完了(**繰越**)も表示して忘れ防止(期限切れ色で上部に出る)
  - **予定のみ**(トグル・既定オフ): オンにすると**開始予定時刻が入ったものだけ**(打合せなど時間が決まった予定の確認)
  - **完了**: **すべて**(既定) / **完了のみ**(振り返り・分析) / **完了を隠す**(残りの作業に集中)
  - **タスク名で絞り込み**: **中間一致**(大文字小文字は区別しない)。`/パターン/` で囲うと**正規表現**
    (`/^報告/` `/(会議|打合せ)/` `/急ぎ/i` など)。`Enter`で**履歴**に残り(直近10件)、次からは候補から選べる。
    `Esc`で消去。正規表現が閉じていない・不正なうちは絞り込まない(打ちかけで全部消えないように)
  - 表示形式は **表ライト**(Excel並みの高密度。行高約2/3・圧縮見出し・1文字ステータス・等幅数字で桁揃え・アイコン操作)
    - 「表形式」「カード形式」は2026-07に一覧から外した(コードは残してあり、`types.ts` の案内どおりコメントを外せば復活可能)
  - 表は**列幅を最適化**(日付・繰返は圧縮、タスク名を最大化)。タスク名は**必ず1行**で溢れはホバーで全文表示。**ヘッダーは固定**(スクロールしても残る)
  - **日付が変わる行の下に濃いグレーの実線**を表示。背景色は使わず、状態色(赤黄緑紫グレー)と競合しない。「今日以降」ビューは常に今日から始まるため、上から見て最初の実線がそのまま「今日はここまで」の目安になる
  - **タスク名列はウィンドウ幅に自動フィット**(広げるほどタスク名が伸びる)。最低幅を下回るときだけ表領域内で横スクロール(ページ自体は横スクロールしない)
  - 列の並びは 日付/区分/状態/重要度/繰返/タスク名/見積/開始予定/終了予定/開始/終了/実績/期限/分類(「残り」は非表示)
  - 並び替えは **待ちフラグ→開始時刻(実績→予定)→終了時刻→重要度→分類名→タスク名** の優先順(日付ごとにまとまる)。
    待ちタスクは重要度に関係なく、その日付の中で常に一番下にまとまる
- **仕事/個人モード**: 「💼仕事/🏠個人/すべて」をワンクリック(`M`キー)で切替。
  仕事中は仕事のタスクだけ、休日は個人のタスクだけを表示できる
  - 仕事/個人は各タスクが持つ属性(ビュー切替のための軸)。**カテゴリとは独立**
  - 新規タスクは今のビューに合わせて自動設定(仕事ビュー→仕事、個人ビュー→個人。すべてビューでは仕事)。フォームでいつでも変更可
  - 前回のモードを記憶して起動
- **カテゴリ**: タスクの分類・集計のためのラベル(例: ビジネスの中の「運用業務」「稟議チェック」など)。
  仕事/個人とは別軸なので、「運用業務(カテゴリ)の仕事タスク」のように掛け合わせられる
  - 入力は**前方一致インクリメンタルサーチ**のコンボボックス(↑↓/Enter/Escで操作。無ければ新規入力可)
  - 新規タスクは、**タイトルが似た既存タスクのカテゴリを自動で初期表示**(部分一致・直近使用分。自分で触ると自動推測は止まる)
  - 候補は文字順に自動整列
- **タスクの開始/終了**: `S`/`E`キー(または開始/終了ボタン)で時刻入力ミニウィンドウが開く
  - 数字4桁(例 `0930`)またはH:MMで手入力でき、「現在時刻」ボタンも常設
  - **開始**: **開始予定があれば予定時刻、無ければ現在時刻を初期値**に(Issue #59。#19の常時現在時刻から変更)。今すぐ始めるときは常設の「現在時刻」ボタンで1クリック。「続き時間(その日の最終終了時刻)」ボタンも付く
  - **終了**: 現在時刻を初期値に。「終了予定(開始予定+見積)」ボタン付き
  - 後からまとめて記録するときに、ボタンで素早く時刻を入れられる
  - この時刻入力ウィンドウは共有部品(`TimeInputDialog`)で、候補ボタンを差し替えて使い回せる
- **実行中タスクのバナー**(Issue #68): 開始したタスクを**ツールバー直下に常時表示**し、「いま何をしているか / いつまでに終えるか」を見失わないようにする。
  - **タスク名・終了予定時刻(開始実績+見積)・残り時間**を表示し、残り時間は**1秒ごとにカウントダウン**
  - 終了予定を**過ぎたら赤くして「超過 +MM:SS」**表示。タスク名クリックでその行へジャンプ、その場で「■ 終了」も可能
  - **タブのタイトル**にも主タスクの残り時間を出す(別タブを見ていても残りが分かる)
  - 終了予定の時刻になったら**ブラウザ通知**を1回発火(バナーの「🔔 終了時刻の通知を有効化」で許可した場合)。見積0のタスクは終了時刻を出せないため通知対象外
  - 表示フィルタ(期間・完了・カテゴリ等)に関わらず**実行中タスクは常にバナーに出す**
- **ステータス**: Excel版と同じく実績から自動判定(完了=終了実績あり/進行中=開始実績のみ/未着手)。
  自分で設定するのは「待ち」フラグのみ(`W`キーまたはステータスバッジのクリックでON/OFF)
  - 待ちは終了時に自動解除
  - 完了タスクで`W`を押すと「待ちタスク」として複製(見積0・実績クリア。Excel版WaitTask踏襲)
- **重要度**: S(最高)〜E の6段階
- **繰り返しタスク**: 毎日/毎週(曜日指定可)/毎月/毎年、完了からX日後に生成する完了トリガー型
  - 日単位は**0日ごと**も指定可能。完了すると同じ日にすぐ次のタスクが作られる(メール確認など1日に何度も行うものに)
  - 表の繰返列は**ひと目で区別**(Issue #18): 開始時刻を**引き継がない=青の⟳** / **引き継ぐ=緑の⟳** / **0日(何度も)=♾️**(繰り返しとは意味が違うルーティンなので別アイコン)
- **中断(割り込み)**: 実行中タスクを「消化分」と「残り」に分割し、割込みタスクを即開始(Excel版ロジック踏襲)
- **コピー**: タスクを複製(`C`キー / コピーボタン)。実行状態(開始・終了実績)はリセットした新規タスクとして作成
  - **開始予定時刻は引き継がない**(Issue #13。コピーは別の時間に置く前提で、同時刻の重複を避ける)。見積時間は残す
  (※以前の「準備」「分割」機能は廃止。Git履歴から復活可能)
- **元に戻す(undo)**(Issue #14): 追加/削除/一括編集/開始・終了/延期/日付移動などの直後、トーストの「**↩ 元に戻す**」または `Ctrl+Z` で戻せる。
  - **1段・自動確定**: 戻せるのは直前の1操作だけ。次の操作をすると自動で確定する(redoは持たない=戻す/やり直しの取り違え事故を防ぐ)
  - トーストが出ない小さな変更(インラインのセル編集など)は対象外だが、**保留中のundoは確定する**ので「あとから黙って消える」ことはない
- **インライン編集**(表): セルを**ダブルクリック**してその場で編集(タスク名/見積/日付/開始予定/開始実績/終了実績/重要度/期限/カテゴリ)。
  **シングルクリックは行選択＋そのセルへカーソルを当てるだけ**(誤爆で編集に入らない。Issue #24)。カーソルセルは `Enter` でも編集できる。
  `Enter`=確定、`Esc`=取消、`Tab`=確定して隣へ。メモ・リンク・繰り返しは詳細ダイアログ(`Enter`/✎)で編集
- **メモの表示・コピー**(Issue #60): メモがあるタスクはタスク名の右に **📝** が付く。
  クリックするとメモ本文を**改行そのまま**で表示し、「📋 コピー」でクリップボードへ(改行も保持)。`Esc`/背景クリックで閉じる
- **一括編集**: 複数選択(チェック/`Space`)して「✏️ 一括編集」で、日付/期限/カテゴリ/重要度/区分をまとめて変更。
  項目ごとに「変更する」を選ぶので「日付だけ更新」もOK。日付は指定セットと「前日/翌日/今日にずらす」の両方に対応。
  「全選択/選択解除」も用意
- **Googleカレンダー連携**: 予定(開始時刻あり)を選んで「📅 カレンダー登録」で専用カレンダーへ登録/更新
  - 一方向(worklist3→カレンダー)の **create/update のみ**。削除はしない(不要イベントは放置。専用カレンダーごと消して再同期できる)
  - 同じタスクの再登録は `gcalEventId` で **重複せず更新**。カレンダー側で手動削除されていたら作り直す(404フォールバック)
  - 件名・開始・終了だけの最小イベント(メモ・カテゴリ等は載せない)。見積0/未設定は15分。タイムゾーンは Asia/Tokyo
  - 時刻のないタスクを含めて選んでも、予定でないものはスキップし、結果を件数で報告
  - Client ID / Calendar ID は 💾 メニューで設定(localStorage保存)。アクセストークンはメモリのみで永続化しない
  - Chrome/Edge の実環境・実Googleアカウント・専用カレンダー・HTTPS生成元が必要(セットアップは別途)
- **クリップボード取込**: `V` キーで、Teamsリンク/Outlook予定/通常テキストを自動判別してタスク化
  - **Teamsリンク**: タスク名は**リンクの表示テキスト**(Excel版 InsertTeamsLink 踏襲)。
    そのためクリップボードの**リッチテキスト(text/html)も読む**。表示テキストが無い・URLそのものの場合は、
    URL以外の最初の行(区切り線は飛ばす)→ それも無ければ `Teams会議`。見積は0分
  - **Outlook予定**: 2行目が「年/月/日」なら予定と判定。1行目がタスク名、日付・開始予定・見積(終了−開始)を取り込む
    (2桁年は2000年代。終了が開始より前なら日跨ぎとみなす)
    - **会議室・応接室**: 3行目以降に `会議室0459` `応接室0415` のような**番号付きの部屋**があれば、
      タスク名の後ろに **【会議室0459】** と付ける(最初の1件。「Microsoft Teams 会議」は番号が無いので当たらない)
    - **来客**: 本文に来客受付(ACALL)の自動挿入ブロックがあれば、タスク名の先頭に **【来客】** を付ける。
      判定は `ACALL Appointment` の目印で行う(「応接室0415(14名_**来客**用)」等での誤爆を避けるため)
    - 例: `【来客】Saviynt【応接室0415】`
    - **重複チェック**: **日付・タスク名(会議室/来客の表記込み)・開始予定・見積がすべて同じ**予定が既にあれば、
      登録せずに「重複」と知らせ、**既存の行へカーソルを移す**。その行が今の絞り込みで隠れているときは、
      見えるようになる最小限だけ自動で緩める(仕事/個人・期間・完了・予定のみ・カテゴリ・タスク名フィルタ)。
      日付が違えば別物なので、**毎週の定例を来週分として貼っても普通に登録できる**
  - 取込しても**すぐには保存されず**、内容を確認できる追加フォームが開く
- **複数タスク一括登録**: 「📥 一括登録」でテキストを貼り付け→プレビュー確認→まとめて追加。
  タブ区切りなら「日付→タイトル→カテゴリ→見積」(Excelからの貼り付け向き)、タブ無しなら「日付 タイトル」やタイトルだけでもOK
  - **もともとの worklist をそのまま取込**(Issue #22): 元Excel/worklistの `day / st / rpt / contents / 時間 / 開始予定 …` の並びを、
    **ヘッダごと貼り付けても**そのまま取り込める(見出し行は自動でスキップ)。列は次のように対応する:
    - `day`「20(月)」のような**日だけ**の表記は、選択日(既定日)の**年月に合わせる**(完全な日付表記ならそのまま)
    - `rpt` の記号を繰り返し設定に変換: **1文字目** `r`=通常/`R`=開始予定時刻も次回へコピー、
      **2文字目** `d`=日/`w`=週/`m`=月/`y`=年、**3文字目**=間隔の数値。例) `rm1`=毎月、`Rw1`=毎週+時刻コピー
    - `st`=`w` は待ち、`開始予定`→予定時刻、`終了`→終了実績、`memo1〜3`→メモ、`theme`→カテゴリ
- **範囲選択**: `Shift`+クリック(基準行〜クリック行)、`Shift`+`↑↓`(キーボードで範囲拡張)。連続時刻・一括編集の対象選びに
- **連続開始時刻**: 選択したタスクに見積時間を積み上げて開始予定を自動設定。
  **選択した順**に割り当てられ(チェックした順に番号が付く)、最初の時刻だけ入力すればOK
- **時刻入力はすべて数字4桁**(例 `0930`。コロン不要)。`0000〜2359` 以外はエラーで弾く
- **定期予定の延期**: 繰り返しタスクを完了にせず「⏭ 次へ」(`P`キー)で次の日程へ移動。「今週はやめた」を1操作で
  - 延期できるのは**未開始のタスクだけ**(Issue #15)。完了・開始済みは延期不要なのでボタンを出さず、`P`キーも弾く
- **ランダム開始**: 🎲 ボタンで今日のタスクから1件をランダムに開始
- **スマートフォン対応**: 画面幅が **640px 未満**だと自動で**モバイル一覧**に切り替わる(PCの表示は一切変わらない)
  - 1行1タスクで、**タスク名・状態・時刻/見積**と**大きな打刻ボタン**(▶開始 / ■終了)を出す。行をタップすると詳細編集
  - 日付が変わるところに区切り見出し(その日の見積/実績の合計つき)
  - **リンクはタスク名の右に絵文字で出す**(Issue #88)。行は増やさず、溢れるのはタスク名の方
    - Google マップは **🗺️**(#86 の「ここにいる」記録から地図へ飛べる)、その他の Web は **🔗**。タップで新規タブ
    - ローカルパスは **📄/📁**。PCと同じくタップでパスをコピー
  - ツールバーは1段に畳み、期間・完了・予定のみ・カテゴリ・タスク名検索は **🔍 絞り込み**の中へ
  - 選択が要る操作(一括編集・連続開始時刻・カレンダー登録)やPC前提の取込はモバイルでは出さない
  - **`?ui=mobile` / `?ui=desktop` で強制指定**できる(無指定なら画面幅で自動)。
    強制中はその旨が出て「自動に戻す」で解除できる。自動のときはURLに `ui` を書かないので、
    スマホで作ったURLをPCで開いてもモバイルが強制されることはない
- **ここにいる記録**(Issue #86): モバイル表示のとき、ツールバーの **📍** でいまいる場所を1件のタスクとして残せる
  - 押すと現在地を取り、座標と精度を見せて「ここですか？」と確かめる。**場所の名前はその場で入力**する
    (空のままなら座標をタスク名に入れる。名前が無いと後から見分けが付かないため)
  - 「🗺 マップで確認する」で Google マップを開ける(**APIキーは不要**)。地名を見て名前を直せる
  - **開始も終了も現在時刻**で完了として記録する。滞在時間ではなく「そこにいた」ことを残すのが目的
  - 座標と精度は**メモ**へ、マップのURLは**リンク**へ入る。`Task` の構造は変えていないので、
    バックアップ・インポート・他の画面はそのまま動く
  - 逆ジオコーディング(座標→地名の自動取得)は**行わない**。APIキーと費用が要るため
  - 位置情報が使えない環境では 📍 を出さない。拒否・取得失敗のときは理由を出して再試行できる
- **URLで開き方を指定**: `?mode=&view=&from=&to=&done=&planned=&category=&q=&ui=` で開ける
  (現在の表示状態はURLに自動反映されるのでブックマーク・共有可能)。標準は「今日以降・完了もすべて表示・予定のみオフ」
  - 例: `?view=custom&from=2026-07-01&to=2026-07-31&done=onlyDone` で7月の完了分だけを振り返る

## ショートカットキー

### タスクへの操作(↑↓でカーソルを合わせてから)

| キー | 動作 |
|---|---|
| `↑` / `↓` | 行(タスク)を移動(青枠で表示。行クリックでも移動) |
| `←` / `→` | 表内で列(項目)を移動(Excelのセル操作の感覚) |
| `h` / `j` / `k` / `l` | **vim準拠でセル移動**(`h`=左 / `j`=下 / `k`=上 / `l`=右)。`←↑↓→` と同じ動き。移動後は `Ctrl+Enter` で詳細を開ける |
| `PageUp` / `PageDown` | 5行ずつ移動 |
| `Ctrl+↑` / `Ctrl+↓` | 同じカテゴリの並びを飛び越えて、前/次のカテゴリの先頭行へジャンプ |
| `Home` | 「今どこをやっているか」へジャンプ: 実行中のタスク→無ければ最後に完了したタスクの次→それも無ければ先頭行。<br>**一覧は先頭から表示**する(カーソル行まで送らない。夕方に押してもその日にやった分が隠れない) |
| `Enter` | カーソルのセルをその場で編集。列未選択なら詳細編集を開く(✎ボタン・編集不可セルのダブルクリックでも開く) |
| `Ctrl+Enter` | 列選択中でも、セル編集を挟まず一発でカーソル位置のタスクの詳細編集を開く |
| `S` | カーソル位置のタスクを開始/再開 |
| `E` | カーソル位置のタスクを終了(繰り返し設定があれば次回分を自動生成) |
| `I` | カーソル位置のタスクを中断(割り込みダイアログ) |
| `W` | 待ちON/OFF。完了タスクの場合は「待ちタスク」として複製 |
| `C` | カーソル位置のタスクを複製(コピー) |
| `P` | 定期タスクを完了にせず次の日程へ延期 |
| `Ctrl+H` / `Ctrl+L` | カーソル位置のタスクの日付を1日戻す/進める(前日/翌日)。**複数選択中は選択したタスクをまとめて移動**(#23)。<br>**トーストが出ている間は並びを固定**(その場で見て`Ctrl+Z`で戻せる)。連打は+N日をまとめて1回のundo。<br>トーストが消えると並べ替え、カーソル位置を画面中央へ。途中でカーソルを動かすと即並べ替えて追従 |
| `Ctrl+K` | カーソル位置のタスクの日付を**今日(当日)へ**移動(#54)。**複数選択中はまとめて移動**。既に今日のタスクは対象外。`Ctrl+H`/`Ctrl+L`と同じく`Ctrl+Z`で取り消せ、トースト中は並びを固定 |
| `Ctrl+Z` | 直前の操作を元に戻す(1段・自動確定。詳細は下記) |
| `Space` | カーソル位置のタスクを選択(連続開始時刻・一括編集の対象) |
| `Delete` | カーソル位置のタスクを削除(確認あり)。**複数選択中はまとめて一括削除**(件数を確認してから) |

### 全体の操作

| キー | 動作 |
|---|---|
| `N` | タスク追加フォームを開く |
| `V` | クリップボードから取込(自動判別) |
| `M` | 仕事→個人→すべて のモード巡回 |
| `?` | **ショートカットキー一覧**を表示(`Esc` / `?` / クリック で閉じる) |
| `Esc` | ダイアログ・セル編集を閉じる(詳細編集フォームは未保存の変更があれば確認してから閉じる)。**複数選択中は選択を全解除**(#24) |
| `Ctrl+Enter` | フォームの保存(どの入力欄からでも一発保存) |

> 日付の前日/翌日移動は「今日」ビューの ◀▶ ボタン(または日付ピッカー)から行います。

## 技術構成

- React 19 + TypeScript
- Tailwind CSS 4
- Vite 7
- データ保存: localStorage(将来のサーバー同期を見据え、`src/lib/storage.ts` の
  `TaskRepository` インターフェースを差し替えるだけで移行できる構造)
- 自動バックアップ: `src/lib/backup.ts`(方針)＋ `src/lib/backupTargets/`(保存先)。
  主保存は localStorage のままで、控えを上に足す構成は変わらない。
  保存先は File System Access API(ローカルフォルダ)と Drive REST(Google ドライブ)の2つ。
  フォルダのハンドルのみ IndexedDB に永続化。アクセストークンはメモリのみ
